# Tic Tac Toe Game 🎮

## 📌 Project Overview
Tic Tac Toe is an interactive two-player game developed using React.js, JavaScript, HTML, and CSS. Players take turns marking X and O on a 3×3 grid. The game automatically detects the winner or a draw and provides restart functionality.

## 🚀 Features
- Two-player gameplay (X and O).
- Automatic winner detection.
- Draw condition detection.
- Dynamic state management using React `useState` Hook.
- Restart game functionality.
- Player score tracking.
- Responsive and user-friendly interface.
- Real-time UI updates.

## 🛠️ Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/gauravsharma646/Tic-tac-toe.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Tic-tac-toe
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🎯 How to Play
1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three marks in a row, column, or diagonal wins.
4. If all cells are filled and nobody wins, the game ends in a draw.
5. Click the Restart button to play again.
